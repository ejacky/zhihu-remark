## 技术债务

| 债务项 | 优先级 | 说明 |
|--------|--------|------|
| 缺乏自动化测试 | 高 | 需要添加单元测试和 E2E 测试 |
| 硬编码 DOM 选择器 | 中 | 知乎更新可能导致失效，需要更健壮的策略 |
| 单文件代码量 | 低 | 部分文件过长，可考虑拆分 |
| 缺少类型定义 | 低 | 纯 JS 项目，未来可迁移到 TypeScript |

---

## 贡献指南

欢迎提交 Issue 和 PR！优先关注的方向：

1. **知乎页面适配**：如果按钮无法显示或内容提取失败
2. **Prompt 优化**：生成质量提升建议
3. **新功能**：参考路线图中的未来版本规划
4. **文档改进**：用户指南、技术文档的完善
