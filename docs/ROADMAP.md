## 技术债务

| 债务项 | 优先级 | 说明 |
|--------|--------|------|
| 缺乏自动化测试 | 高 | 需要添加单元测试和 E2E 测试 |
| 硬编码 DOM 选择器 | 中 | 知乎更新可能导致失效，需要更健壮的策略 |
| 单文件代码量 | 低 | 部分文件过长，可考虑拆分 |
| 缺少类型定义 | 低 | 纯 JS 项目，未来可迁移到 TypeScript |

> 完整的架构问题清单、逐条状态跟踪与验收标准见 [`docs/ARCHITECTURE_REVIEW.md`](ARCHITECTURE_REVIEW.md)（2026-10-10 全量评审：11 项 P0 缺陷 / 10 项 P1 / 5 项 P2 / 8 项文档漂移）。本节仅保留方向性描述，具体条目以该文档为准。
