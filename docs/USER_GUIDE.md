# 使用说明

> 适用于 v2.0 重构后的版本。面板已简化：不再有错误类型、置信度、风格切换。

## 1. 安装

1. 打开 `chrome://extensions`（Edge 用 `edge://extensions`），打开右上角「开发者模式」
2. 点「加载已解压的扩展程序」，选择本仓库根目录（含 `manifest.json` 的那层）
3. 改过代码后的重载方式：content 改完刷新知乎页面；background 改完在扩展页点刷新；改过 `manifest.json` 必须重新加载扩展

## 2. 如何使用反驳助手

在知乎问题页、推荐页或专栏文章页，每条回答的底部操作栏会多出一个「🛡️ 生成反驳」按钮。点击后扩展会提取回答正文，交给你配置的 AI 生成一条评论草稿。

**扩展不会替你发布任何内容**，所有对外动作都需要你自己点发送。

## 3. 生成反驳

1. 点「🛡️ 生成反驳」→ 卡片立刻出现，显示「正在思考…已 N 秒」
2. 默认开启深度思考，通常等 **30~60 秒**（面板会持续计时；超过 20 秒会提示"可以先干别的"）
3. 生成完成后卡片里是一段**可以直接发的评论**，通常 2~4 段
4. 三个动作：
   - **填入评论框**：自动填进知乎评论框（失败时自动复制到剪贴板）
   - **换个说法**：换角度重写一版
   - **✕**：关闭。关掉后再点同一回答的按钮会恢复上次结果，**不会重新请求 AI**（省钱）
5. 审核、按需修改，然后自己点发送

失败时卡片会显示具体原因（Key 无效 / 额度不足 / 域名未授权 / 生成被截断），并给一个「重试」按钮。

## 4. 设置

点扩展图标直接打开设置页（没有弹窗面板了）。**主界面只有四项**：

| 项 | 说明 |
|---|---|
| API Key | 必填，只存在本机 |
| 模型 | 必填。先点「同步模型」从服务商拉取列表再选，也可手填任意模型名 |
| 深度思考 | 默认开。开：先推理再作答，30~50 秒，质量更好；关：1~3 秒出结果 |
| 保存历史记录 | 默认开。保留最近 10 条，下面的列表里可查看与清空 |

其余项收在**「高级设置（一般不用改）」**里：提供商、API Base URL、反驳风格、自定义 Prompt 后缀。

- **提供商**：DeepSeek / Kimi / OpenCode Go / OpenAI / Claude / 自定义。
- **API Base URL**：内置提供商默认只显示内置地址，不用手填；需要代理 / 镜像时勾选「使用自定义地址」再填。保存时浏览器会就该域名弹一次授权（OpenCode Go 的 `opencode.ai` 也一样），拒绝则不保存。
- **模型**：「同步模型」会向所选服务商请求模型列表：OpenCode Go 无需 Key，其余提供商先填好 Key（列表来自你的账号）。同步失败时可直接手填模型名。
- **反驳风格**：全程生效（卡片里不再切换风格）。

### 4.1 API 设置

| 提供商 | 内置地址 | 说明 |
|---|---|---|
| DeepSeek | `https://api.deepseek.com` | 模型名如 `deepseek-v4-pro`、`deepseek-v4.1-flash` |
| Kimi | `https://api.moonshot.cn/v1` | |
| OpenCode Go | `https://opencode.ai/inference/go/openai/v1` | 需订阅 OpenCode Go；点「同步模型」直接选；首次保存会请求 `opencode.ai` 权限 |
| OpenAI | `https://api.openai.com/v1` | |
| Claude | `https://api.anthropic.com/v1` | |
| 自定义 | 无（必填） | 任何 OpenAI 兼容端点；同步模型时尝试 `{地址}/models`，没有该端点就手填 |

> 用 OpenCode Go 时，先在 Console 填好 API Key，再点「同步模型」选模型（如 `deepseek-v4.1-flash`）。并先在 Console 的 Privacy › Regions 里选 **Global**，否则会被网关拒绝。

## 5. 打开设置

点扩展图标即可直接打开设置页（没有弹窗面板了）。生成相关的操作都在知乎页面上的卡片里。

## 6. 常见问题

**按钮不出现？** 先刷新页面；扩展刚装或刚更新后，已打开的知乎页面需要刷新一次。

**一直停在「正在思考」？** 深度思考单次 30~60 秒属正常。超过 90 秒没结果，关掉卡片重试；反复如此请检查设置里的模型名是否正确。

**提示「域名未授权」？** 设置页重新保存一次配置，在浏览器弹窗里点「允许」。

**提示「生成被截断」？** 思考与正文共用同一份 token 预算（固定 16384，不再作为设置项）。换一个更省思考预算的模型，或关闭「深度思考」后重试。

**会不会被知乎封号？** 扩展不自动发布、不自动点赞，所有动作都由你手动触发，行为和你自己打字评论一致。

**隐私？** API Key 与生成记录只存在本机 `chrome.storage.local`；扩展没有任何后端，请求直接发给你的模型服务商。
